# Task Management System (MERN)

A full-stack Task Management System built using MERN Stack.

## Features
- User Registration & Login
- JWT Authentication
- Protected Routes
- Create, Update, Delete Tasks
- Task Categories
- Priority Levels
- Dashboard Analytics
- Dark Mode
- Responsive UI

## Tech Stack

Frontend:
- React
- Tailwind CSS
- Axios
- React Router

Backend:
- Node.js
- Express.js
- MongoDB Atlas
- JWT
- bcrypt
